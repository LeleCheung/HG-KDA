# HG-KDA 文档工作区

更新：2026-10-15。当前用于维护 HG-KDA 的研究定位、三条工作线、阶段进展和项目依据。代码由各线独立仓库维护，后续待各仓库成熟再考虑集合方式。

HG-KDA（Hardware-Grounded Kernel Design Agent）研究如何结合硬件证据与优化知识，通过“硬件证据 → 瓶颈假设 → 知识引导的候选生成 → 实验验证”迭代优化算子。硬件证据的范围包括真机 profiling、RTL 仿真与分析、周期精确模拟和指令流分析；各平台已接入的能力不同，不能将研究范围写成已实现能力。
